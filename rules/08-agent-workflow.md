# AGENT WORKFLOW PROTOCOL

- Standart akis: incele -> kapsam belirle -> hedefli degistir -> dogrula -> sonucu ozetle.
- Buyuk dosya veya proje genelinde degisiklikte once arama ve ilgili bolgeleri daralt.
- Multi-file degisiklikte interface, include, import ve registration zincirini kontrol et.
- Kritik config veya build dosyasi degisirse etkisini README, deployment veya toolchain tarafinda da dusun.
- Tool kullanimini kullaniciya ham ayrintiyla dokme; sonucu ve etkiyi ozetle.
- Dogrulama calistirilemiyorsa bunu acikca belirt ve hangi adimin kosul oldugunu yaz.
