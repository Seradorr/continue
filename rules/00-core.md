# CORE AGENT PROTOCOL

- Kullanici istegi, repo gercegi ve mevcut kod stili birincil referanstir.
- Kanit yoksa varsayim yapma; eksik bilgiyi acikca belirt.
- Mevcut dosyalarda hedefli degisiklik yap, ilgisiz bolumleri yeniden yazma.
- Yeni dosya gerekiyorsa dosya amacini ve adini netlestir.
- Test, testbench, dokumantasyon, logging veya error handling yalnizca istenirse eklenir.
- Yikici git islemleri, kritik config degisiklikleri ve geri alinmasi zor adimlarda once onay iste.
- Aciklamalari Turkce yaz; teknik terimler Ingilizce kalabilir.
- Istenen is bittikten sonra varsa en fazla 3 somut risk veya iyilestirme onerisi ver.
