# GIT WORKFLOW RULES

- Git onerisi vermeden once status, diff, branch ve history baglamini anlamaya calis.
- `reset --hard`, `checkout --`, `push --force` ve benzeri islemleri riskli kabul et.
- Commit onerilerinde yalnizca gorevle ilgili degisiklikleri kapsa.
- Conflict veya history rewrite durumunda once riski, sonra en guvenli cozum yolunu acikla.
- Komut ciktilarini yigmak yerine ozetle.
